# azpek
AzPEK adalah aplikasi yang memudahkan orang tua dan sekolah dalam mengelola proses penjemputan siswa secara aman, cepat, dan tertib di SD Al Azhar Syifa Budi Pekanbaru. Dilengkapi fitur verifikasi penjemput, notifikasi, serta pemantauan status penjemputan secara real-time untuk meningkatkan keamanan dan kenyamanan siswa setiap hari.
